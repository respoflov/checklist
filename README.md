# 체크리스트 (Checklist)

여러 개의 리스트를 만들어 할 일을 체크하는 가벼운 PWA입니다. 설치 없이 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 동작합니다.

- 배포: https://respoflov.github.io/checklist/
- 후속 앱: 이 앱을 전면 개조한 [Docheck](https://github.com/respoflov/docheck)

## 주요 기능

- 리스트 여러 개 만들기·이름 바꾸기·삭제
- 항목 추가·수정·완료 체크, 드래그로 순서 바꾸기
- 마감일 지정과 마감일순 정렬, 오늘 마감 표시
- 라이트·다크 테마 전환
- JSON 백업 내보내기·가져오기

## 파일 구성

```
index.html      앱 전체 (HTML·CSS·JS 한 파일)
manifest.json   PWA 설치 정보
sw.js           오프라인 캐시 서비스 워커
icon-*.png      앱 아이콘 (180·192·512·512 maskable)
```

## 데이터 저장

모든 데이터는 이 기기 브라우저의 `localStorage`에만 저장되고 어디로도 전송되지 않습니다. 브라우저 데이터를 지우면 함께 지워지니, 중요한 목록은 백업 내보내기로 보관하세요.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다. 홈 화면 설치와 오프라인 캐시는 HTTPS 주소(GitHub Pages 등)에서만 켜집니다.

## 홈 화면에 추가

- 아이폰: 브라우저에서 주소를 연 뒤 공유 버튼(↑) → 홈 화면에 추가
- 안드로이드: 브라우저 메뉴(⋮) → 홈 화면에 추가 또는 앱 설치
